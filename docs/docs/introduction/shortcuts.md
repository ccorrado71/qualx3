# Keyboard and Mouse Shortcuts

!!! note
    On macOS use the Command key wherever this page says Ctrl.

## Mouse in the graphic area

| Action | Effect |
|--------|--------|
| Mouse wheel | Horizontal zoom |
| Ctrl + mouse wheel | Vertical zoom: the bottom of the pattern stays fixed and only the top of the intensity range changes |

Bars of peaks and phases below the pattern keep their size during the vertical
zoom. Use **Reset Zoom** (Ctrl+0) to return to the full view.

## Keyboard

| Shortcut | Action |
|----------|--------|
| Ctrl+N | New |
| Ctrl+P | Print |
| Ctrl+0 | Reset Zoom |
| Ctrl+E | Load/Add Entry by ID |
| Ctrl+Return | Accept Selected Entries |
| Del | Delete Selected Entries |
| Esc | Clear Selection in the Results List, Peaks and Quantitative lists (the list must have the keyboard focus) |
