# Data Reduction

Before running a Search & Match, the raw diffraction pattern usually needs
to be processed. QualX provides the following data reduction tools:

| Tool | Menu | Description |
|------|------|-------------|
| [Background](background.md) | Pattern → Background | Estimate and subtract background |
| [Peak Search](peak-search.md) | Pattern → Peaks | Detect peak positions and intensities |
| [Smoothing](smoothing.md) | Pattern → Smoothing | Reduce noise |
| [K-α2 Stripping](kalpha2-stripping.md) | Pattern → K-α2 Stripping | Remove the Kα2 contribution |

All tools are accessible from the **Pattern** menu.
